# AgenticThat

AgenticThat is a website-driven social publishing and scraping workspace with a
local desktop Companion for protected browser sessions and execution.

## Companion downloads

- [Windows, macOS, and Linux v2.1.1 QA downloads](https://github.com/tinitiateprime/agentic-that/releases/tag/v2.1.1-qa.2)
- [Stable Companion v2.0.0](https://github.com/tinitiateprime/agentic-that/releases/tag/v2.0.0)

The v2.1.1 QA packages are unsigned compatibility-test builds. Use them for
Windows, macOS, and Linux testing, not as the signed production release.

See [the project tracker](agentic-that-project-tracker.md) for implementation and
deployment status.
