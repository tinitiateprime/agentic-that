# AgenticThat Companion 2.1.12

- LinkedIn video publishing keeps the browser open while the provider displays upload, processing, or posting progress.
- Companion waits for the progress notice to disappear and remain settled before reporting the post as complete.
- Slow large-video uploads can remain active for up to two hours by default while the durable job lease continues to be refreshed.
- The macOS release pipeline builds ZIP and DMG sequentially and restores the native DMG helper before creating a verified disk image.

This QA release is unsigned and intended for owned-account validation on Windows, macOS, and Linux.
