# AgenticThat Companion 2.1.20

## Reliable YouTube Community images

- Selects only YouTube image inputs instead of a generic video/file input.
- Waits for large images to finish decoding and uploading without submitting the same file twice.
- Handles YouTube's image editor before checking the final Community preview.
- Recognizes current preview controls, image renderers, and background-image previews.
- Reports YouTube's visible rejection message instead of a generic preview timeout.
- Optimizes oversized still images without cropping, while preserving normal images and animated GIFs.
- Stops safely before the Post action unless the image preview is confirmed.

## Release scope

- Includes Windows x64 installer and portable ZIP builds.
- Includes universal macOS DMG and ZIP builds.
- Includes Linux x64 and ARM64 DEB, RPM, and portable ZIP builds.
