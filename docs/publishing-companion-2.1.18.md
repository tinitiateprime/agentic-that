# AgenticThat Companion 2.1.18

## Smooth LinkedIn managed Page selection

- Opens a slug-based managed Page through its exact link in LinkedIn's Manage card instead of trying an ambiguous admin URL first.
- Goes directly to the Page selected in AgenticThat, including the second or later managed Page.
- Avoids the duplicate LinkedIn feed reload before managed-Page publishing.
- Expands collapsed and longer Manage lists before matching the selected Page.
- Keeps numeric organization-ID destinations on the verified direct route.
- Stops safely without submitting when the selected Page is no longer available.

## Release scope

- Includes Windows x64 installer and portable ZIP builds.
- Includes universal macOS DMG and ZIP builds.
- Includes Linux x64 and ARM64 DEB, RPM, and portable ZIP builds.
