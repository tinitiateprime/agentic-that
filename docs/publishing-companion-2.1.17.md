# AgenticThat Companion 2.1.17

## LinkedIn managed Page publishing

- Accepts LinkedIn's canonical numeric organization ID when a saved public Page slug redirects into Page administration.
- Falls back to the exact Page link in the LinkedIn Manage card before opening Page posts.
- Prevents an older queued-post account snapshot from erasing managed Pages discovered by a newer login.
- Keeps the final publish action guarded; navigation failures stop without submitting a post.

## Release scope

- Includes Windows x64 installer and portable ZIP builds.
- Includes universal macOS DMG and ZIP builds.
- Includes Linux x64 and ARM64 DEB, RPM, and portable ZIP builds.
