# AgenticThat Companion 2.1.19

## Reliable LinkedIn Manage-card navigation

- Uses a trusted pointer click for the exact managed Page selected in AgenticThat.
- Verifies that LinkedIn actually leaves the feed after the Manage-card interaction.
- When LinkedIn suppresses the first Page click, opens only that exact validated Manage-link destination.
- Never falls through to another administered Page.
- Keeps the final publish action guarded; unresolved navigation stops without submitting.
